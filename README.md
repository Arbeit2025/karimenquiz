# karimenquiz

普通自動車の仮免許（仮免）学科試験対策のための、○×（まるばつ）カード形式クイズアプリです。単一ファイルの Flask アプリで、問題はすべてこのリポジトリ内で完結します。

## 概要

- 全100問のオリジナル問題を4カテゴリ（各25問）に収録
  - 交通ルールの基礎
  - 標識・標示
  - 運転の基本
  - 歩行者と安全
- モード：ランダム10問 / 全問100問 / カテゴリ別（25問）
- 回答するとその場で正解・不正解と解説を表示
- 結果画面で正答率と合格ライン目安（90%）を表示し、間違えた問題だけを復習できる（間違えた問題はブラウザの localStorage に保持）
- ライト/ダーク表示の切り替え対応、外部リソース不使用

## 免責

本アプリの問題は、道路交通法の基本的な内容をもとに独自に作成した**学習用の自作問題**です。**公式の試験問題ではありません**。実際の試験対策は、教習所の教本など公式の教材とあわせてご利用ください。

## 使い方

```bash
pip install -r requirements.txt
python3 app.py
# http://localhost:5000 を開く
```

本番相当の起動（Render 等）：

```bash
gunicorn app:app
```

## API

- `GET /` — クイズ画面（問題データは JSON として埋め込み）
- `GET /api/questions` — 全100問を JSON で返す
- `GET /healthz` — `{"status": "ok"}`

## テスト

```bash
python3 -m unittest discover -s tests
```
